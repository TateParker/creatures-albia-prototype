# Feedback at Association Limits Design

## Intent

Keep Praise and Scold feedback truthful when the affected learned association is already at its 1 or 0 clamp.

## Behavior

- Compare the association before and after the existing ±0.2 adjustment.
- If the value changes, retain the current stronger/weaker explanation.
- If it does not change, explain that the association is already at its strongest or weakest in the Norn reason, event journal, memory, and toast.
- Preserve the valid feedback action and existing social observation behavior at a limit.

## Constraints

- Keep clamping, feedback eligibility, observation rolls, event links, save fields, and decision formulas unchanged.
- Do not add or run automated tests under the standing user instruction.
